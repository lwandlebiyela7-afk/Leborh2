# For Leborh 💖

A little romantic web page made with love.

## Put it online with GitHub Pages

1. Create a new repository on GitHub (e.g. `for-leborh`).
2. Upload `index.html` and this `README.md`.
3. Go to **Settings → Pages**.
4. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
5. After a minute, your page is live at `https://YOUR-USERNAME.github.io/for-leborh/`.

Send her the link. 😊

## Make it yours

Open `index.html` and look for the `✏️ EDIT` comments:

- Change the typed messages in the `lines` array.
- Rewrite the six cards with your own reasons.
- Replace the letter with your own words.
- Change the pop-up messages in the `messages` array.
